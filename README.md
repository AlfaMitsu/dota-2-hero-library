# Dota 2 Hero Library

Next.js App Router + React + Tailwind CSS 4 + shadcn/ui components.

Run `npm install` and `npm run dev`; then open http://localhost:3000.

Features: responsive four-attribute hero grid, Ogre Magi-style hover video pop-out, clickable hero profile with animation, lore, abilities, talent tree, cached OpenDota stats, level 1–30 interactive calculator, favorites and search.

Animations and latest stats require an internet connection, while local cropped portraits work offline. The rotating viewer is a CSS tilt effect, not genuine 360-degree 3D geometry.
